## ⚙️ Як активувати GitHub Pages
1. Перейдіть у репозиторій: **Settings** ⚙️ → **Pages**.
2. У розділі **Branch** оберіть **`main`** та папку **`/ (root)`**.
3. Натисніть **Save** — сайт запрацює за посиланням вище.

---

## ✂️ Про проект
- **Стек:** Чистий HTML5 / CSS3 / Vanilla JavaScript у єдиному файлі `index.html`.
- **Без сторонніх бібліотек чи збірки:** Працює як статичний файл при відкритті в будь-якому браузері.
- **Зручна конфігурація:** Усі дані закладу (назва, контакти, послуги, посилання на онлайн-запис Altegio) налаштовуються в блоці `window.BARBER_CONFIG` на початку файлу `index.html`.
