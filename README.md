## ⚙️ Як активувати GitHub Pages

1. Перейдіть у репозиторій: **Settings** ⚙️ → **Pages**.
2. У розділі **Build and deployment** (Source: *Deploy from a branch*) у полі **Branch** оберіть **`main`** та папку **`/ (root)`**.
3. Натисніть **Save** — за декілька хвилин сайт запрацює за посиланням вище.

## ✂️ Про концепцію та дизайн

- **Візуальний стиль:** Індустріальний та стриманий характер ("Grit"): кольори графіту, бетону та сланцю з теплим мідно-помаранчевим акцентом.
- **Типографіка:** Контрастний конденсований шрифт **Oswald** для акцентних заголовків та чистий геометричний **Inter** для тексту (Google Fonts з повною кирилицею).
- **Стек:** Чистий статичний HTML5 / CSS3 / Vanilla JavaScript у єдиному файлі `index.html`. Працює як локально без збірки, так і через будь-який веб-сервер.
- **Мобільна адаптивність & Accessibility:** 
  - Mobile-first верстка зі зручною фіксованою панеллю швидких дій знизу (виклик по телефону + онлайн-запис).
  - Усі інтерактивні елементи мають мінімальну висоту кліку 44px.
  - Контрастність тексту перевищує стандарт WCAG AA (4.5:1).
  - Реалізовано `skip-link` («Перейти до вмісту») та чіткі `:focus-visible` контури.
- **Дані закладу (публічна інформація):**
  - **Адреса:** вул. Бориса Грінченка, 2, Київ (інтерактивна мапа Google Maps та кнопка «Прокласти маршрут»).
  - **Телефон:** 098 234 4234.
  - **Онлайн-запис:** [Altegio (n1431451.alteg.io)](https://n1431451.alteg.io).
  - **Графік роботи:** «Графік уточнюйте за телефоном».
  - **Фішка сервісу:** «Кава під час візиту».
- **Зручна конфігурація:** Усі параметри закладу, списку послуг і галереї редагуються в блоці `window.BARBER_CONFIG` на початку файлу `index.html`.
